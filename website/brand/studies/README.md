## Newvar N

[newvar-n.svg](newvar-n.svg) 采用用户提出的变形规则：保留 Morphz M 的左片，将右片围绕水平中线上下翻转。两片轮廓沿用 `public/brand/morphz-mark-cyan.svg`；变换为 `translate(0 96) scale(1 -1)`。

M 的左右对称由此转为 N 的旋转对称。两个标识共用几何单元，以变形建立家族关系。后续重点检查中央折口、两片间距和小尺寸下 N 的辨识度。
