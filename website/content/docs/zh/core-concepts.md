Morphz 的正式机器身份是 **S-Expression Cognitive Machine（S 表达式认知机）**。它以 S 表达式承载可执行的认知状态、程序、约束和求值入口：语言模型作为可替换的非确定性语义处理器提出认知与行动，Runtime 作为确定性事务内核验证结构、权限、因果、版本和持久化。

## 代理

Agent 是认知机加载身份、认知策略、工具边界和默认行为后的实例。它不是 Morphz 的基础机器定义，也不是某个模型账号或一次模型请求。

## 认知上下文

认知上下文是代理持有的长期认知范围。它包含当前认知结构、认知帧、观察、关系和可召回账本。多个会话可以共享一个认知上下文，因此新会话不等于失忆。

## 会话

会话是用户、代理或外部通道之间的沟通流。它负责消息顺序和交付目的地，但不独占认知上下文。归档会话不会删除认知上下文中已经形成的认知。

## 认知帧

认知帧是认知上下文中可寻址、可版本化的认知单元。它可以承载事实、约束、计划或形成中的理解，并带有来源和生命周期。认知帧退役后不会从账本中消失；需要时可以通过召回查回。

## 线程与激活

线程表示一条持续的工作线；激活是运行时对这条工作线的一次具体执行机会。激活可以结束，线程仍可等待下一次事件继续。子线程的生命周期归属于父线程或独立持久目标，而不是偶然触发它的某次激活。

## 目标

目标表示需要跨多轮持续推进的意图。它持有目标状态和收敛条件，运行时可以在进程重启或临时模型失败后继续调度。目标完成前，最终交付仍属于目标生命周期的一部分。

## 模型服务与模型路由

模型服务描述请求发往哪里、采用什么协议；认证账号描述使用哪个身份；物理模型是服务真正接受的模型名；模型路由给用户提供稳定选择并决定候选路径。这些对象必须保持分离。

## 一次请求的边界

```text
用户消息
  → 会话接收
  → 认知上下文编码
  → 线程获得激活
  → 模型尝试
  → 运行时校验工具或文本结果
  → 提交事件与认知变化
  → 向目标会话交付
```

这条边界解释了为什么模型响应成功、工具执行成功和最终交付成功是三个不同状态。
