# Selected-passage discussions
Mode: Operate/Read. Extend existing Desktop and Dashboard; preserve their identities, message typography, source grants and main drafts.

## Direction contract
THESIS: Reading and discussion share the selected passage. “加入对话” keeps the existing main-draft path; “讨论” opens an independent stream beside the source. Multiple passages run independently.

OWN-WORLD: Existing neutral paper/ink surfaces in both themes, semantic teal actions, system text roles and existing Markdown. Compact 28–32px controls; one restrained popover surface, no nested cards or decorative gradients.

STORY: Select a passage, choose 讨论, type immediately, send, read its result and follow up. Reopen another discussion without changing main chat. An optional initial switch also publishes the same native messages to the main conversation.

FIRST VIEWPORT: A two-action selection toolbar. A source-anchored 360px panel with compact header, two-line source excerpt, paged stream, and two-line composer. History stays scrollable; primary send is a 30px icon at the composer edge. Older discussion/history pages load only on request.

FORM: A local extension, not a replacement visual world or concept tournament; source-attached reading pane. seed: not applicable (local extension; new-work.md line 41)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
