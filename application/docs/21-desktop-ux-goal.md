### 本轮架构与语义修正

- 语音服务实现通过 `SpeechProvider` 接口接入中心；状态响应携带提供方标识及显示名。朗读／听写不绑定品牌，具体服务与传输说明进入按需详情。当前仍仅实现豆包适配器，不宣称提供任意引擎切换界面。
- 批注和人工事项结果是中心写入，不依赖模型连接；不显示无关的 Agent 离线告警，不提供不支持的新增附件／截图动作，保留已有附件的移除能力。
- 通知读取失败与设置写入失败分离，轮询不覆盖写操作结果、失败提示或新状态。
- 文档首标题去重仅作用于显示 AST；目录／搜索摘要仅用于显示，保存内容、检索命中引用及版本不改写。
- 执行详情的长输入默认只占两行，可展开全文；重复的单分支标题改为直接入口，执行目标 ID 收入详情。没有待批事项时不常驻显示审批说明。
- 附件与输入选项使用不同的 React key，修复切换工作现场后重复／残留的附加文件按钮；原生文件选择期间暂停失焦收起，选择、取消和上传结束均释放状态。取消固定按钮会移除自身，因此先将焦点交回文字输入，不把控件卸载误判为用户离开。
- 版本切换进入已有对象工具栏；来源身份与只读信息进入正文中的紧凑可展开区域，不再叠版本栏、来源栏。窄窗口将文字动作收为有名称的图标，并在窗口变化后保留当前应用标签可见。
- 浏览器书签状态读取本空间实际保存的网站对象，不依赖组件生命周期内的临时数组；重新打开或刷新后仍能识别已保存网页。
- 短听写实测发现空识别结果会无说明返回准备态。现在每次采集单独追踪是否完成及是否得到文字，在采集结束、队列清空且没有错误时才显示“未识别到文字，可重新听写／录音”；复用原状态位置，不增设状态栏。连续输入、旧草稿、失败重试和取消语义不变。
- 点击关闭内嵌听写时，卸载关闭按钮会使焦点落空并收起整个输入。点击关闭与 Escape 现在共用退出路径，先将焦点恢复到稳定的语音入口，再卸载听写；真正点击外部仍自动收起，长录音模态仍使用共享模态焦点恢复。
- 原窗口随后出现用户带截图的反馈“选不到 pdf，因为被遮挡”：确认实际系统选区可以产出图片，但产品把截图弹窗和灰色遮罩留在待截画面上。截图准备阶段现在隐藏弹窗、遮罩与输入／交流浮层，保留模态约束、原画布位置及草稿；等待原生浏览器布局回执与渲染绘制后才启动系统选择。取消、失败、成功均恢复确认界面和按钮焦点；重新选择失败不丢旧预览，准备期间取消也不允许迟到选区启动。浏览器截图时恢复网页，进入确认后再次遮挡原生网页，不开启协助权限。
