# 桌面界面规范

> 本文保留早期界面约定。现行规则见 [Morphz UI 设计规范与优化方案](./16-ui-design-standard.md)，实际完成项见 [实施记录](./13-implementation-status.md)。公共输入与交流、搜索与弹窗、单行应用标签栏已实施；下文有冲突的旧布局不再作为开发依据。

MorphzWork 是围绕对象协作的工作工具。界面分为导航、内容与输入三层；对话和对象占据同一个主工作区，批注是对象的辅助检查器。Session 不出现在产品导航中。

## 设计依据

参考 Apple 的 [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars) 和 [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：

- 利用桌面空间，同时保持舒适的信息密度，不把重要内容埋入多级弹窗。
- 导航、当前对象的操作、主要内容各自承担清晰职责。
- 侧边栏默认可见，也可以收起；窗口缩小时保留核心操作。
- 保留系统窗口控制和键盘操作。macOS 标题栏与工具栏整合，其他桌面系统保留标准窗口边框。

这是基于 Electron 的跨平台界面，不宣称使用了 AppKit 原生控件或系统 Liquid Glass 材质。Web 入口不会绘制假窗口控制。

## 窗口与导航

- 侧边栏包含事项、工作台、项目、项目列表、最近修改；用户与连接状态位于底部。
- 桌面侧边栏保持 280px，不随中等窗口宽度压缩；窄 Web 窗口切换为顶部导航。需要更多内容空间时可以主动收起侧边栏。
- 顶部使用一排工具栏：侧边栏开关、内容位置、内容/对话切换、输入框开关、外观、对象批注。
- 窗口标题反映当前对象或项目，不重复用应用名称充当内容标题。
- 窄 Web 窗口以紧凑导航替代完整侧边栏，不隐藏核心入口。

## 内容与输入

- 工作台是未命名为项目的持久工作空间，使用应用启动台与应用页签。保存为项目保留对象、Session 和应用实例，再生成空白工作台；不跨项目聚合。
- “项目”主导航打开项目目录；点击项目卡片或侧边栏名称进入其工作空间并恢复应用。每个项目可以打开不同的认知应用，专业界面不由固定内容集合替代。完整约定见[认知应用与工作空间](./15-cognitive-application-host.md)。
- 输入框明确标注当前空间及对象引用，随空间导航切换底层 Session。同空间多个应用共用对话；输入草稿仍可按对象或应用分别保存，避免串入其他编辑内容。项目目录中的输入归到工作台。
- 对象集合支持标题搜索、类型筛选、卡片/列表布局；默认按最近修改排序。筛选只改变视图，不产生新的对象副本。
- 文档使用安静的阅读画布；版本、编辑、批注和关联操作保留明确入口。切换对象从顶部开始，切换对话不会卸载对象编辑器或丢弃草稿。
- 事项使用可扫描的任务行，显示标题、工作要求摘要、优先级、执行状态和截止日期。
- Human 和 Agent 的发言处于同一主内容流，通过署名与样式区分来源；失败、排队、未发送状态保持可见。
- 输入框固定在主工作区底部并居中，与对话采用相同阅读宽度；保留对象/版本/选区上下文。
- Cmd+J / Ctrl+J 显示或隐藏输入；Enter 发送，Shift+Enter 换行，中文输入法确认候选词时不发送。

## 外观

- 保留 Dashboard 的四组主题数值：电光青、鸢尾紫、暖珊瑚、纯单色。
- 强调色用于图标、输入焦点、主要动作和品牌标记；大面积背景使用中性灰阶，不再使用蓝紫底色。暗色主画布为 #202020，侧边栏为 #171717；亮色为白色与 #f2f2f2。
- 明暗模式通过 CSS 数据属性应用，支持亮色、暗色和跟随系统；测试检查实际计算颜色，而不只检查按钮选中状态。
- 文本、图标、按钮、边框、圆角和间距使用统一规范；不加入没有对应功能的装饰性按钮。

## 验证

`npm run build` 和 `npm test` 检查类型、构建及数据/协议边界。`npm run test:e2e` 验证对象编辑、版本冲突、引用、批注、关联、输入和集合操作，并生成多种宽度及四主题明暗截图。

`npm run test:desktop` 在独立临时数据目录和开发端口启动实际 Electron 窗口，检查渲染隔离、快捷键、侧边栏、macOS 拖动区域和最小窗口尺寸。此测试不会替换正在运行的用户中心或向用户数据添加视觉样例。

当前改动不扩展 Runtime 能力，不加入模拟 Agent 回复；浏览器自动化、其他 Artifact 查看器和完整原生菜单命令映射另行实现。
