# 桌面能力实施路线

状态：本轮四个里程碑已完成 macOS 开发版验收。实现范围、实测方式与边界见[桌面能力实施记录](./13-implementation-status.md)；不代表未实测平台或正式发行包已交付。

## 本轮范围

以 Desktop 为交付入口，先在现有 macOS 环境验收。沿用 Electron 与共用的 Web 界面，不增加独立 Web 产品发布、浏览器扩展或 Mobile 工程。移动端及其他入口在桌面经过实际使用和多轮打磨后再开展；未实测的桌面操作系统不标记为已支持。

桌面连接一个中心服务。当前用独立的本地服务进程模拟远端中心，验证显式连接、身份、断线重连和数据一致性；不部署公开云服务，也不把放开监听地址当作完成云端接入。界面不得直接读取中心数据库或在每个窗口建立独立 Agent。

应用层负责对象、视图和协作入口，Morphz Runtime 仍负责认知、上下文事务、调度与执行。必要时补充正式 Runtime 接口，不在客户端重造调度器，也不通过直接修改 Runtime 数据库实现控制。

Human 与 Agent 都是 Actant；Principal 表示身份和授权来源。所有对象读取、修改、分派和执行使用可验证的身份、范围、修订及操作标识。

## 里程碑

### 1. 资料接入、检索与 Agent 对象操作

- 资料从用户明确选择的文件或目录进入，分别表达导入副本和外部来源引用；记录来源、内容修订及同步状态。
- 先接入 Markdown、纯文本及现有图片类型，随后扩展 PDF。其他格式仍在路线内，但不通过伪装成纯文本来声称支持。
- 对项目、对象标题与正文进行可定位的检索。结果带对象、版本和可打开的引用；授权过滤发生在结果进入模型之前。
- Agent 可以查找、读取、创建、修订和关联对象，与人使用同一领域规则。并发修改返回冲突，不静默覆盖；重复请求不重复创建对象。
- 补齐真实执行详情、审批、停止与错误恢复。保存操作和 Runtime 接受操作应明确区分。

完成标准：接入资料后，Agent 能基于来源创建可打开的文档；人批注后 Agent 修改同一对象，版本和引用保留；退出重启后仍可接续。测试覆盖未授权来源、过期版本、重试、取消和恢复，不依赖人工复制聊天回复。

### 2. 持续关注、任务协作与当前理解

- 支持定时、来源变化等事件触发，以及可暂停、取消的长期关注项；复用 Runtime 的调度与依赖能力。
- 事项可由 Agent 自主安排并分派给 Human 或 Agent。人可以调整负责人、模型策略、优先级和时间，UI 显示实际生效状态。
- 请求、待决策项和交付进入 Inbox。人工响应必须匹配当前事项、身份和修订，随后解除对应等待，不影响无关并发工作。
- 提供与工作相关的“当前理解”：目标、约束、关键事实及可公开的来源。人提出纠正后，由 Agent 通过上下文事务更新；不暴露隐含推理，也不要求人维护底层上下文。
- 通知按优先级和用户设置呈现，重复事件不重复创建事项或连续打扰。

完成标准：持续关注能够跨进程重启恢复，相关变化形成事项，分派和人工响应驱动真实工作接续；暂停后不再产生新执行；模型策略变更不混入其他事项。

### 3. 内置浏览器与交互式产物

- 内置浏览器作为桌面中的对象宿主，支持导航、网站登录、持久浏览器配置、页面读取、获准操作和人机接管。
- 人接管后旧控制权立即失效；Agent 恢复前重新获取页面状态。外部提交结果未知时先核对，不能自动重复提交。
- 外部网页、可信应用界面、Agent 生成的交互式产物使用分离的权限和隔离边界。
- 先提供实用的表格、表单及交互报告。数据与版本属于中心对象，不依赖渲染进程临时状态；生成代码默认没有凭据、任意网络和文件访问权限。
- 网站限制嵌入式登录时明确报告；本轮不为绕过限制而复制凭据，也不因此把浏览器扩展加入默认交付范围。

完成标准：在测试网站中完成读取、填写、人接管、Agent 接续与结果确认；验证账号不串用、导航后旧动作失效、断线不误报成功。交互产物在重开后保留状态且不能越权访问应用能力。

### 4. 桌面语音与现场输入

- 使用豆包语音服务，提供语音输入、朗读及围绕当前对象的语音批注。语音只提供输入／输出能力，不取代 Morphz 的共享认知和工作协调。
- 支持显式发起的截图、选区和文件输入，带上对象或项目范围；不持续采集全屏、麦克风或其他应用内容。
- 麦克风授权、录音与发送状态可见。停止后停止采集，断线、拒绝授权和取消均有清楚反馈。
- 凭据只在服务端使用，测试音频先使用合成或明确授权的样例；真实语音调用和权限验证单独记录。

完成标准：在真实桌面窗口中录音、确认或取消输入、得到真实识别结果；对象朗读可停止；语音批注关联正确对象和版本。配置存在但未完成服务调用，不算语音通过验收。

## 测试与安全边界

- 真实资料只取明确指定的项目文档；写入、同步变化和删除测试使用独立临时目录和数据库，不对源码资料做破坏性验证。
- 目录接入禁止默认扫描系统盘、用户主目录或扩展到选定目录之外；不跟随越界符号链接。
- 索引及模型输入排除 `.env`、凭据、数据库、版本库内部数据、依赖目录和构建产物。允许接入一个目录不意味着允许读取其中的秘密。
- 本地模拟中心通过与实际部署相同的连接和身份契约，验证至少两个测试身份、会话可见性、撤销、断线和重复请求。测试替身与真实 Runtime 的通过记录分开保存。
- 可以自主改代码、运行隔离测试、进行必要的本机集成。不会因此自动获得发帖、发邮件、付费、修改真实业务数据、公开部署、推送或发布版本的授权。
- 需要用户处理的登录、验证码、系统权限或账号开通，及时指出具体动作；其他不受影响的工作继续推进。

## 完成判定与顺序

按上述顺序建设正式能力，不重复制作仅能演示预设流程的原型。每个里程碑记录实现范围、回归结果、真实连接验证、尚未验证的平台与外部条件。

暂不以签名安装包、商店上架、公开云部署或移动端验收作为本轮完成条件。也不能把这些延期项写成产品已经具备的能力。

本轮实施与验收已完成，后续进入桌面实际使用和体验打磨；平台扩展、打包和发布另行安排。
