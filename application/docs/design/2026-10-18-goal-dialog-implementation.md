入口。本轮是现有视觉系统的局部延伸，没有新建产品身份或接入组件库。

## 当前实现

目标全文是主阅读路径。阅读态使用上限 600px 的共享 dialog 宽度变量，
标题与真实状态在左，补充、复制、暂停／恢复、更多和关闭图标在右。
复制依据用户后续反馈从更多移到标题区。更多只放编辑、执行记录和删除；
阅读态没有常驻底部工具栏。编辑、记录、删除均在同一原生模态内切换，
保留必要错误、只读、离线与 busy 状态。删除确认只说明后果和确认选择，
不重复铺满原目标。记录仅列已加载的准确关联执行，有界范围明确可见。

正文是保留换行的纯文本语义段落，不经过 Markdown 解析。复制直接取
完整原字符串，进入编辑以原字符串填充；保存仍经过现有非空、长度及
修订校验。不会把两行侧栏摘要当作可编辑或可复制的目标全文。

| 文字角色           | 当前源码与计算目标     | 归属                           |
| ------------------ | ---------------------- | ------------------------------ |
| 对话框标题         | 14px；沿用共享标题行   | `ui.css`／共享 dialog frame    |
| 目标状态           | 12px／18px             | 目标标题组                     |
| 密集详情正文       | 14px／1.6；段距 0.65em | `ui.css` 共享详情 token        |
| 桌面编辑／删除说明 | 14px／1.6              | 同一共享详情角色               |
| 粗指针编辑         | 16px；沿用已有输入规则 | 共享 dialog frame 的输入 token |

首轮局部实现使用 15px／1.7，用户认为过大；本轮恢复密集详情的层级，
不是将所有文稿阅读一起缩小。编辑使用 `field-sizing: content`，最小
高度为 `min(140px, 32vh)`、最大为 `min(44vh, 340px)`，保留可调高度；
340px 是上限，不是短内容的固定占位。阅读区长文内部滚动、短文随内容
收缩，沿用共享模态的窄窗、短窗和缩放边界。

菜单 Escape 先关闭菜单并将焦点归还更多。编辑、记录或确认态 Escape
回到阅读态，阅读态再关闭并恢复查看入口；不连带关闭主体栏。只读与
断线保留全文及复制，禁用真实写入操作；错误不伪装成功。

## 业务与数据边界

补充使用 Runtime 已授权的当前目标代次与唯一准确关联执行的 continuation。
Host／客户端沿用原输入读取和授权能力，界面有界补齐原输入历史，随后
复核身份、仍在查看的目标和请求有效性，再调用最新共享输入命令。
该动作只准备既有输入框中的可取消关联，不发送、不重建原消息、不清空
原草稿。目标切换或关闭、身份变化、原输入不可读、执行／代次不符时，
迟到结果不得改变输入框。最终发送仍走原提交与 Runtime continuation 校验。

编辑扩展既有 typed `objective.control`，沿用 Runtime 已有
`PATCH /api/objectives/:id`，提交 `expected_revision` 与
`stated_objective`。Host 复核实际发起 Human、原项目／会话、Session、
当前授权与目标修订，Web 入口保留身份代次／CSRF 边界。没有 Rust 修改、
新增模型调用、工具列表变化、目标业务表或第二份持久化权威。

编辑不自动恢复暂停目标；后台修订变化时保存被阻止并保留编辑草稿。
暂停／恢复和删除沿用现有操作，未知回执先读取核对，不自动重复写入。
删除停止自动推进并留下 cancelled 目标、已有内容和执行历史，不撤回
已发生的外部操作，也不将正常关闭窗口当作停止执行。
