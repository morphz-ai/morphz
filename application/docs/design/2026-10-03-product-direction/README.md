## 历史探索 A（暗色）

这是一个精确、有深度的工作界面，而不是管理后台或霓虹演示台。

- **整体构图**：深色导航与主体信息形成稳定边界，中间工作画布略亮。层次来自成组的亮度、排版、留白与边缘，不给每个功能都套框。
- **品牌信号**：沿用 Morphz 蝶形 M 与青色。青色集中在输入焦点、可继续的内容与真正的运行状态，不把整个界面染成品牌色。
- **文字层级**：正文最清晰，标题靠字重和节奏而非夸张尺寸；时间、来源与工具信息退到次一级。中文长内容而非空白占位是构图基准。
- **入口分工**：应用 Dock 是有独立材质的快捷入口；阅读、固定、收起是轻量局部动作。输入与阅读沿同一锚点接续，不把右側动作收进输入工具。
- **运行表达**：运行态使用小尺度有方向的轨道与步骤流动，不靠整张卡片呼吸。结束后归于稳定对勾，需要处理则明确停下；尊重减少动画偏好。

## 历史探索 B（亮色）

这是更强调阅读与作品的编辑室。它不仅换了浅色：正文仍用易读系统字体，
作品标题引入中文衬线；继续工作从浮起的卡片改为连续的编辑版面，
应用目录以分隔行组织，交付内容去掉外框，以纸面与细线区分。
青色保持同一品牌，但使用适合浅底的深前景色。

不再推荐其中一个作为产品体系；明暗与强调色应独立，四种既有强调色保持。
下面的操作只用于查看历史试验，不作为生产功能验收。

## 可以评审的交互

- 左侧切换对话、事项、内容库、工作台；项目入口和新对话草稿入口保持分工。
- 工作台区分成功打开记录的继续工作与应用入口，保留应用浏览／管理入口。
- 事项列表保留日期分组；看板是同一示例对象的独立四列投影。
- Dock 切换文档／剧本工作画布；不提交消息、不启动活动。
- 工作页可展开当前交流或保持仅输入，聚焦输入不擅自展开记录；专用对话页常驻消息与输入。
- 右栏切换活动、授权、安排、设定；点击活动标题展开子 Thread 分组与步骤。
- 顶部「状态演示」显示运行／结束／需要处理。执行结束不等于事项完成。
- 模型强度、Profile 停用、输入固定为本页展示状态；不写入真实参数。
- 搜索、对话框、箭头页签、Escape 与可见键盘焦点可用。

原型未实施完整业务操作；窗口拖拽、原生输入、运行恢复、语音、目录授权等仍由现有实现负责。
所有潜在能力入口均显式提示演示边界。
