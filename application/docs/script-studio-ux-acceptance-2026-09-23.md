## 功能取舍

| 功能                         | 取舍与边界                                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 剧本列表、搜索、项目归属     | 保留。多剧本直接可见；归属是整理同一对象，不是复制文稿或移动会话。                                             |
| 创作目录                     | 保留并修复。宽窗口可收放，窄窗口覆盖画布而不是挤走正文；目录分组和集场层级不变。                               |
| 正文编辑、保存、版本历史     | 创作主流程。未保存草稿独立保留，刷新、切换和后台改版不能覆盖它。                                               |
| 生成、改写、连续性和影响检查 | 保留具体目的，但按钮只准备可编辑输入，不暗中发送；普通聊天仍可调用同一工作能力。                               |
| 候选稿                       | 是备选稿，不是正文版本。序号、最新生成、待选数量分开表达；采纳才产生正文版本。                                 |
| 过期候选                     | 标记旧稿并保留阅读与比较，不再算待选，不要求逐个拒绝。不绕过版本保护强行采纳。                                 |
| 审阅意见                     | 保留锚定正文版本的意见、解决记录与阻断原因；结构检查不能冒充内容质量审查。                                     |
| 人工审批、锁稿               | 可选功能，移出正文主流程。明确实际审阅人，不声称提交会通知别人或启动智能体，也不冒充完整多人协作。             |
| Word 导出                    | 普通创作文稿无需审批。另保留明确选择的正式交付，仍要求有效锁稿。两类文件均固定已保存版本；创作副本标记其用途。 |
| 设置、结构资料、追溯信息     | 按需展开或从现有设置入口进入，不占据正文主空间；不删除权限、来源或历史记录。                                   |
