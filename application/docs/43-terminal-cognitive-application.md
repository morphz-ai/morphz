# Terminal 认知应用

状态：2026-10-16 已实现本机 Terminal，原 Morphz.app 真实模型、命令链路及 Desktop 重开验收通过；平台边界见下文。

## 产品边界

这是内置应用，不是执行记录换名，也不是重新实现一种 Shell。
Runtime 在明确的本机执行节点上运行系统 Shell 的真实 PTY；Agent 对同一
Terminal Session 输入、读取、调整大小、发送中断和关闭。`cd`、环境变量、
交互程序和输出都属于这个会话。已有 `exec` 独立保留，不静默改成终端。
应用切换、收起交流、关闭应用页签和 Desktop 重开不结束 Runtime 的会话。
终端进程退出或 Runtime 丢失物理句柄后如实显示，绝不重放旧命令来“恢复”。

界面以 Agent 操作为主，创建和关闭通过共享交流入口交给 Agent；用户也可
直接在同一终端键入、粘贴和发送 Ctrl+C，不必经过模型，不增加第二个聊天框。
界面直接读取实际终端屏幕，不读取整条 Thread 历史，
不把终端输出自动塞进模型上下文。Agent 显式读取有界屏幕／回滚窗口。
远程执行节点未具备 PTY 传输前明确拒绝，不偷偷切回本机；普通远程 exec
保持原有能力。远程 PTY 仍未实现。

## 数据模型和所有者

Runtime 拥有 `terminal_sessions` 和人工控制回执 `terminal_commands`；Platform
只保存应用导航（选中的终端 ID）。
进程句柄、终端解释器和有界回滚缓冲区在 Runtime 物理所有者内；不进入
Renderer，不放到工作区 JSON，不伪造为持续运行的 Agent Thread／目标。

每个终端有稳定 ID、创建 Job、原始 root、Session、Context、发起 Principal、
执行节点、Runtime 实例、控制 revision、状态、所有者租约、Shell、初始 cwd、
权限边界指纹、最后一次输入的 Job 身份／提交回执，以及有界屏幕检查点。
身份、归属、状态、租约和查询键使用关系列；屏幕是有大小上限的派生快照，
不是业务正文或全量日志。屏幕更新不改变控制 revision。历史记录不因关闭
界面而删除；结束进程是显式操作。没有自动上传、云端搬移或秘密注入。

SQLite 和 PostgreSQL 使用相同身份、CAS、限额和查询语义；迁移只新增表和
索引，不重写消息、目标、Session 或既有 Job。查询先按 Principal、Session、
Context 及授权 root 限定，再排序／LIMIT；不能先取一页全局数据再猜权限。
索引服务于上述限定和时间排序，唯一 ID／创建 Job 防止重复创建。

## 执行、安全和并发

Agent 工具仍先经过真实 ExecutionJob、原发起身份和执行节点路由。创建
固定当时的系统沙盒、目录和网络边界；后续输入复核有效权限和成员身份。
权限收紧不能让旧 Shell 继续持有更大权限；应结束旧会话并清楚说明原因。
不能靠检查输入字符串代替操作系统沙盒，也不能借 Host／Renderer 绕过审批。
首版不通过终端自行请求额外路径、网络或秘密；需要扩大权限仍走已有 Human
设置和审批机制，不能把安装／打开应用解释成授权。

控制操作使用 expectedRevision；并行写同一终端冲突时须重新读取，不能
交错覆盖。Agent 使用工具 Job 身份；人工输入使用不可变 command ID，
请求摘要绑定发起人、Session、Context、终端、revision 和输入。人工回执
不保存输入正文、不注入模型 Context；两条链共用权限、物理控制锁和 CAS。
重复身份返回原回执，不再次输入；同一身份改参数拒绝。写入前先保存“提交结果待核对”，
写入后保存“已提交”；回执不确定时不重试物理输入。已提交只证明 PTY
接收了输入，不等于命令执行成功；结果须从真实输出／程序状态核对。

进程由 Runtime 管理，读取、写入、内存、会话数和输出大小都有边界。
屏幕租约／检查点更新独立于模型运行，不能让终端持续输出卡住 App。
Runtime 重启后租约失效的会话显示连接丢失，保留最后检查点、不重新执行。

## 验收门槛

- 原有 exec 回归；真实 PTY 的 cwd／环境延续、中文、ANSI、交互输入、
  Ctrl+C、尺寸变化、退出、关闭和输出洪流。
- 两种数据库的迁移、限定后 LIMIT、CAS、重复创建／输入、旧检查点及重启
  丢失语义；跨 Principal／Session／Context／节点和撤权都拒绝。
- 真实 Client 读取走共享 Application 逻辑，Web HTTP 与 Desktop typed IPC
  共用；切换／关闭页签不停止进程，无重复发送或整条 Thread 拉取。
- 明暗、窄窗、键盘可达、状态／错误、回滚和复制；原 Morphz.app 用现有
  profile／中心验收 Agent 工具到可见终端的真实命令，不以 fixture 代替。

## 使用方式与实现范围

从工作台／全部应用打开 Terminal，使用原共享输入框让 Agent 创建会话和
执行命令。页面上的新建、解释输出等快捷操作只准备草稿，用户发送后才
执行；打开、恢复或切换应用不创建 Shell。点击已连接的终端即可直接输入，
共享交流框仍是唯一 Agent 意图入口。多个会话通过页签选择。

Runtime 的 `terminal` 工具提供 open、list、read、write、interrupt、resize、
close；原 `exec` 仍是独立非交互命令能力，不混用输出或会话状态。
新 Terminal 输入采用精确的 13（未选择）／14（已选择）格式，只携带冻结
的导航引用、不携带屏幕正文。1—12 既有格式和已经排队的请求不改写。
导航引用本身不是权限；所有操作仍验证真实 Job、发起身份、Session、Context、
执行节点及当前权限。终端目录显示“起始于”，不把初始目录冒称当前目录。

单 Runtime 最多八个 live PTY，默认 24×80、上限 60×160；回滚最多 500
行。Agent 的显式 read 返回一个窗口，纯文本最多 24,000 字符并声明截断；
可按 sequence 等待新输出，单次最多五秒。富文本检查点不超过 512 KiB，
异常密集 ANSI 时简化样式但保留可见文字。界面只在激活时读取，隐藏即停
UI 轮询，不停止进程；输出流与检查点没有无界队列。

写入使用真实 Job 身份和 revision；提交待核对时保留可读屏幕，但禁止
继续写入、调整和中断，直到明确关闭旧会话。不以新 Job 绕过未知回执。
工具执行记录直接展示真实输入命令，不添加猜测目的。屏幕输出视为不可信
数据，转义呈现；不执行输出中的 HTML 或把输出当作新指令。

## 验证记录（2026-10-16）

### 直接键盘输入与完整配色

原先的手绘屏幕只有读取能力，不能按终端用户的习惯直接输入；现使用
xterm.js 处理按键、组合输入、粘贴、选择、光标和字形。它不持有进程，
仅把显式键盘事件提交到共享 Application 的 `terminal.command`，再由
Runtime 复核原工作来源和权限。Web 写路由经过 Origin 和 CSRF 校验；
Desktop 走同一个类型化业务操作，不新增本地应用 HTTP 服务。

键盘队列最多 16 KiB，按 UTF-8 切成最多 4096 字节的串行批次，冻结版本
和 command ID。超限不截断执行；未知回执停止后续输入、保留未确认文字
供复制，不自动重发。切换应用不在后台补发；撤权后不能凭旧 metadata 写入。
只读历史和断开的检查点不能输入。打开页面不会创建进程或发送消息。

配色使用 [Catppuccin Latte 和 Mocha](https://catppuccin.com/palette/)，
覆盖背景、正文、标准 ANSI、选择和光标；保留真彩色、扩展色及减少动态
偏好。主题按中心和身份保存，默认跟随应用，也可只把 Terminal 设为深色。
运行输出仍先由 Runtime 解析为有界单元格，再转换成受控 SGR／光标指令；
不把原始 OSC、DCS、HTML、剪贴板指令或输出中的指令交给浏览器执行。

本批正式 Node 七文件 44／44、Playwright 三文件 9／9、Rust Terminal

同一 Shell 保留，并再次实际输出 `reopen-ok:中文粘贴已保留`。原 Runtime
