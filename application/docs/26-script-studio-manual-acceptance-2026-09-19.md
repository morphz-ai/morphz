## 待修问题

### F01 · P1 · 准备请求被拦截后，刚填写的要求丢失

复现：

1. 统一输入框为空，仅保留“构思新剧”意图标签。
2. 在已保存分集中点击“生成候选”。
3. 填写本次要求，将字符上限从 8000 改为 1000，点击“准备到输入框”。
4. 出现“输入中已有另一份请求……”提示，弹窗关闭。
5. 移除空意图，再次打开生成弹窗：要求为空，字符上限回到 8000。

实际影响：没有输入正文的标签也阻止当前操作；准备失败却销毁了刚输入的要求。用户必须重新填写。

修复边界：保留真实的已有输入保护；准备结果要明确返回成功/失败，失败不关闭弹窗、不清空要求。空意图与有正文的请求分开处理，不静默覆盖已有正文。

源码定位：`apps/web/src/App.tsx:2218` 的输入冲突判断；`apps/web/src/ScriptStudioEditor.tsx:817` 在调用 `onCompose` 后无条件关闭生成弹窗。

### F02 · P2 · 导出状态跨剧本残留

复现：之前的测试剧本完成导出后，新建并切换到本次新剧本。新剧本导出历史为 0，但顶栏仍显示 `TEST 剧本修复验收 0919-b0dc277c.docx` 的“Word 已保存”提示。

实际影响：用户容易把另一部剧的导出成功误认为当前剧本的结果。

修复边界：导出提示必须绑定所属剧本/导出记录，切换时清理或展示对应状态。

源码定位：`apps/web/src/ScriptStudio.tsx:120`、`:373`。

### F03 · P2 · 同一次失败重复提示，且页面跳动

复现：新建空分集后点击“提交审阅”。“请先填写正文。”同时显示在剧本顶栏下和文稿区域内。带阻断意见批准失败时，背景页面和决定弹窗也同时显示错误。

功能保护有效：空稿没有送审，阻断意见没有被绕过。但重复错误占用两处空间，推动正文和按钮位置变化。

修复边界：保留一处就近、可操作的错误；模态内的失败由该模态承载，不再同时在背景重复铺设。

源码定位：`apps/web/src/ScriptStudio.tsx:384`、`apps/web/src/ScriptStudioEditor.tsx:205` 及决定弹窗的错误处理。

### F04 · P2 · 内部标识直接进入用户界面和 Word 交付稿

手动观察：

- 审阅人显示 `local-human`、`morphz-agent`，历史操作直接显示 `revise / submit / approve / lock / unlock / invalidate`。
- 历史中的上游对象以 UUID 显示，用户难以对应目录中的文稿。
- 导出历史按钮主要用八位 ID 区分，而不是所含分集、版本等可读信息。
- 实际导出的 Word 首页和正文间包含项目 UUID、导出 UUID、ISO 时间、`local-human（local-owner）`、文稿/依赖 UUID。文件可打开，但技术追溯信息压过交付稿正文。

修复边界：不删除审计数据；默认使用可读名称与中文动作，技术标识放到详情或追溯附件。Word 默认呈现适合阅读的稿件，追溯信息有清楚的次级位置。

源码定位：`apps/web/src/ScriptStudioEditor.tsx:606`、`:670`、`:1050`；`apps/web/src/ScriptStudio.tsx:585`；`packages/core/src/script-studio-docx.ts:341`。

### F05 · P2 · 标签页方向键缺失，成功操作后的焦点不稳定

复现：聚焦“历史”标签后按右方向键，既不移动焦点，也不切换到“检查与影响”。这些元素声明为 tab，却只有点击切换。

多次手动新建、保存、采纳、退回、批准后，焦点返回 HTML 页面根部；取消和 Escape 大多能回到触发按钮。失败批准后按 Tab 仍回到模态内部，未观察到模态焦点逃逸。

修复边界：补齐标签页左右键/Home/End 和明确的焦点顺序；成功导致按钮禁用/移除时，转移到文稿标题、当前标签或下一项可操作控件。

源码定位：`apps/web/src/ScriptStudioEditor.tsx:211`。焦点现象以本次 AX/键盘记录为证据，不把纯 CSS 断言当作通过。

### F06 · P2 · 修正与保存动作距离问题现场过远

手动观察：

- 父集采纳新稿后，分场“检查与影响”只能看到“引用的上游版本已变化”，没有跳到对应引用或修改位置的动作。
- 实际修正需要返回正文、展开“结构、来源与连续性信息”、滚到底部更换依赖版本，再滚回顶部找“保存文稿”。
- 项目规范表单展开 Word 模板后，标题/关闭与保存/取消不能同时保留在视口；放大后仍可滚动到按钮，不是完全不可操作。
- 取消原生导出后只提示“从历史重试”；真正入口在概览的“导出历史”，与文稿“历史”标签不同。

修复边界：保持当前页面/目录布局；给问题就近的定位动作，固定必要的表单保存/取消操作，导出取消提示明确指向“概览 → 导出历史”。
