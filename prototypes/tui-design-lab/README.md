# Morphz Terminal UI Lab

这是一个与正式 Ratatui 实现隔离的视觉实验台，用来先确认：

- 亮色与暗色终端中的前景色策略；
- 信息密度与全屏会话布局；
- 工具调用的极简、摘要和展开层级；
- 对话消息与任务执行的分离；
- Agent / Context / Session / Viewer 的层级表达；
- 只显示当前身份有权访问的 Session，并展示驻留、换出与隔离状态；
- 可检查但不暴露思维链的 MIND 认知视图；
- 当前 Session 与整个 Context 的工作范围切换；
- 运行中、等待中和依赖阻塞任务的调度视图；
- 输入区、运行状态和快捷键的视觉优先级。

页面不会加载外部字体或资源。预览底色只用于模拟用户终端；最终 TUI 应继续使用终端原生背景色。

交互快捷键：

- `Ctrl+W`：在完整对话视图与完整任务视图之间切换；
- `Ctrl+M`：在完整对话视图与 MIND 认知视图之间切换；
- `Esc`：从任务或认知视图返回对话视图；
- `Ctrl+1`：查看当前 Session；
- `Ctrl+2`：查看整个 Context；

顶部 Session 选择器只展示 `viewer/shafreeck` 在当前演示中有权读取的会话。选择隔离会话时，Context 也会随挂载关系切换；这只是身份过滤和挂载模型的交互原型，不代表浏览器本身负责鉴权。

运行：

```bash
cd prototypes/tui-design-lab
python3 -m http.server 4178 --bind 0.0.0.0
```

然后在同一台机器打开 <http://127.0.0.1:4178/>，或从局域网使用运行机器的 IP。
