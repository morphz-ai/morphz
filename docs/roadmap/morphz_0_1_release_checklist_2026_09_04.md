## 已知发布边界

- Windows 与 macOS 包尚未配置商业代码签名。0.1 是源码优先的 Developer Preview；下载的二进制可能触发系统信誉提示，文档不提供绕过系统安全检查的命令。
- SQLx 的锁文件仍记录未启用的 MySQL/RSA 可选依赖；当前任何 workspace 包、feature 和 target 都无法到达该依赖。审计脚本只豁免对应的 `RUSTSEC-2023-0071`，并在 RSA 变为可达时立即失败。
- Rust 依赖审计另报告 4 个停止维护和 1 个撤回版本提示，均来自上游间接依赖且不属于已知漏洞；后续随上游升级替换。
