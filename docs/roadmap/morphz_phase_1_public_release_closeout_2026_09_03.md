# Morphz 第一期公开发布收口清单（2026-09-03）

> 发布范围：预编译安装、源码、双语论文、Morphz 技术主站
> 发布身份：Morphz 0.1 Developer Preview
> 当前判定：尚未达到公开发布条件；工程主体已具备基础，许可证与品牌身份仍为硬阻塞项
> 适用关系：本文定义第一期公开波次，不替代完整的 0.1 发布就绪规范和后续安装分发计划

## 1. 第一期究竟发布什么

第一期建立四个相互校验的公共入口：

1. **预编译安装**让陌生用户通过一条命令获得经过校验的原生制品；
2. **源码**证明 Morphz 是可以检查、构建和验证的真实实现；
3. **论文**定义计算模型、证据范围、实验结果与有效性边界；
4. **主站**用一致的产品语言组织理念、论文、源码与公开文档。

四个入口共同围绕同一中心命题：

> **From Chat Completion to Structured Context Evaluation.**
> 从聊天补全走向结构化上下文求值。

第一期把预编译安装包和一条命令安装作为发布门槛，但不以公共云、官方人格、完整商业产品、
跨组织认知协作或生产级部署作为发布门槛。这些内容继续保留在完整 0.1 规范及后续发布波次中，
不应在第一期主站上被暗示为已经交付。

## 2. 发布判定原则

四个入口必须作为一个整体开放，不能分别留下互相矛盾的产品身份、能力边界或版本信息。

满足下列全部条件后，才能将这次动作称为 **open-source release**：

- 公开源码拥有明确、有效、覆盖实际发布范围的开源许可证；
- 论文和规范文本的公开复制、引用与贡献边界已经确定；
- 网站中的产品主张不超出论文与源码能够支持的范围；
- 发布 commit、论文 PDF 和线上站点均能被唯一定位和回滚；
- Morphz 的名称、Logo、视觉素材和 Newvar 署名拥有明确来源与使用权。

在源码许可证确定前，GitHub 仓库即使可以访问，也只能称为 **source-available preview**，
不能称为开源发布。

## 6. P0：主站公开 Gate

### 6.1 品牌身份

首期品牌工作的对象是 **Morphz 产品**，Newvar 以 “Created and maintained by Newvar”
作为背书品牌出现。Yao 语言的括号交叉为“爻”的构想属于独立语言标识，不与 Morphz 产品
Logo 混用。

当前站点中的 `(Morphz)` 文字标识具有明确的 S-Expression 语义，可作为正式方向继续发展；
现有 `og.png` 中的蓝紫色抽象 M 更接近通用 AI 图形，且文案仍使用旧的 “Agent Runtime”
定位，不应直接作为最终 Logo 系统。

正式品牌包至少包括：

- [ ] 主标志与矢量母版（SVG）；
- [ ] 横向组合、纯图形标志和纯文字标志；
- [ ] 深色、浅色、单色与反白版本；
- [ ] 16/32px favicon、应用图标和社交头像；
- [ ] 1200×630 Open Graph 图；
- [ ] 安全留白、最小尺寸、色值、字体和禁止用法；
- [ ] 原始设计文件、字体许可和素材权属记录。

验收标准是：16px 仍可辨识、单色仍成立、与常见 AI 渐变 M 有明显区分，并能解释 Morphz
的结构化 Context / 求值边界，而不是仅仅“看起来像 AI”。

## 8. 收口执行顺序

1. **冻结发布身份与 IPR 决策**：许可证、专利、贡献和商标政策先于正式公开；
2. **完成 Morphz Logo 系统**：先定语义与矢量母版，再替换 favicon、OG 和站内标识；
3. **收敛源码与分发入口**：重写 README，补 Security，建立 Release 制品、安装器、干净 clone 与扫描 Gate；
4. **完成主站最后调试**：SEO、链接、可访问性、性能、部署和回滚；
5. **冻结论文**：人工通读、元数据、公开 URL、最终 PDF 与哈希；
6. **执行三面一致性审查**：源码、论文、网站逐字段核对；
7. **建立 RC，并在各支持平台完成一条命令安装预演**；
8. **在同一窗口开放仓库、Release、论文和主站，再发布对外消息**。

## 9. 第一阶段完成定义

只有当以下陈述全部为真，第一期才算完成：

- 陌生开发者能够理解 Morphz 是什么、当前能做什么、不能承诺什么；
- 他拥有合法使用和贡献源码所需的明确许可；
- 他可以通过一条命令安装，也可以从源码构建，并能把论文中的主要主张反查到公开实现或证据；
- 论文、网站和源码使用同一身份、同一版本和同一能力边界；
- Morphz 拥有可识别、可复用、权属清楚的品牌标志；
- 线上发布可以监控、回滚，不依赖作者工作区中的隐式状态。

完成这一步以后，官方人格、云服务与更完整的陌生用户引导体验再作为下一波发布能力推进，
而不是反向阻塞第一期的四个核心入口。预编译分发和一条命令安装已经属于第一期完成条件。
