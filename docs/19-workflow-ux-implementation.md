# 用户路径整改记录

日期：2026-09-10。范围是现有 Desktop 的使用路径，不是新增一套专业编辑器，也不是将实验 UI 包提升为 Runtime 标准。

后续继续复查见[体验复查记录](./20-experience-review.md)。下述验证是本轮历史证据，不代表后续改动已经逐页通过 Computer Use 验收。

## 统一原则

让用户先做事，再决定是否保存为内容或项目。界面操作、输入作用范围、Session、后台执行和权限必须分别处理，不能靠切换 Session 或暗中授权来缩短路径。

认知应用声明可选的 `ui.presentation`：`workspace` 保留宿主导航，`immersive` 隐藏外层侧栏与标签栏。省略时为 `workspace`，浏览器也默认 `workspace`：侧栏由用户自己折叠，主区以地址工具栏替代外层标签栏，不堆双层 Header。沉浸式全屏指占满当前窗口，不是自动切换系统全屏。宿主保留返回入口；应用只呈现场景所需的工具和内容，不重复标题。

## 已实现路径

| 场景 | 现在的交互与边界 |
| --- | --- |
| 浏览网站 | 启动浏览器即可输入网址；不需要先让 Agent 创建网站。地址、导航、保存、协助与输入共用一行工具栏。 |
| 返回工作空间 | 同一工作空间内保留原生网页和未提交表单，返回不等于关闭。隐藏即撤销临时协助授权。关闭应用、退出、切换中心或由其他空间替换原生页面后，只恢复已保存地址，不承诺保留表单。 |
| 网页协作 | 新输入携带当时的 pageId、epoch、URL 和标题。它们是数据，不是权限；原生宿主与服务端仍检查当前页面和授权。 |
| 截图输入 | 选择范围、预览、添加到原草稿，可补文字再发送；默认不进内容目录。另有显式“保存到内容”。 |
| 消息附件 | 图片、PDF、TXT、Markdown 可附到草稿、就地预览和移除。上传时禁用发送，失败保留草稿及已上传附件；重试保留投递 ID 和字节。附件-only 输入也能发送。 |
| 对象现场交流 | 默认投影当前对象相关输入及真实交付；浏览器按应用实例投影。可以展开全部历史，底层仍是原会话。 |
| 选区操作 | 文档和 PDF 选区旁可提问、批注、朗读。批注通过同一输入区保存，明确“不发送给 Agent”；版本与引用不丢失。 |
| 听写／长转写 | 短听写在输入框内，明确开始后才采集，停止／关闭终止采集，请求与原草稿绑定，不自动发送。长录音转写入口保留完整长文保存流程。 |
| 连续朗读 | 原文保留，紧凑播放器非模态呈现；播放才请求供应商，暂停、语速、章节与恢复沿用长文管线，不设置整本书的 2000 字限制。 |
| 输入／内容／来源 | 给消息附文件、导入为内容、连接持续同步文件夹是不同入口。启动台可直接连接文件夹；原来源界面保留状态与授权确认。 |
| 执行与成果 | 默认当前工作，可切全部；普通聊天不冒充交付任务。精确成果名称可直接打开，原始参数和回执置于技术详情。 |
| 版本 | 搜索固定版本与真正过时的历史版本分开表达，唯一的当前 v1 不再误标为旧版本。 |
| 项目与事项 | 启动台提供最近非事项成果、浏览器和本空间内容入口；人工事项主层展示待处理等直接状态，内部安排状态留在详情。 |
| 通知与理解 | 通知设置收进齿轮，不再伪装为列表筛选；无公开理解时先给梳理动作，不先要求人纠正空内容。 |
| 窗口和页签 | 模态按主内容区居中；关闭活动应用回到相邻页签，最后一个才回启动台；保存工作台用“为当前工作命名／保存为项目”说明保留与重新开始。 |

## 验证

- 类型检查、生产构建及 104 项 Node 测试通过。
- 最终完整界面回归 **73/73 通过**。新增用例覆盖独立浏览器、单行布局、附件草稿和预览、截图默认附件、选区批注、交流投影、输入框内听写、通知设置与居中。现有回归包含四主题、窄窗口、任务回应、权限、会话、版本冲突、流式显示及长语音／百万字朗读。首轮 70/73，三个旧断言分别仍要求全局历史默认摊开、人工事项显示“已计划”、应用网格上方没有“继续工作”等内容；更新交互断言后重新运行了完整套件，而非仅复测失败项。
- `test:browser` 使用真实 Electron 原生页面与本机合成网站，验证不创建 Artifact 的浏览、未提交表单保留、临时授权失效、原生页面紧贴唯一工具栏，以及原有快照、填写、逐次批准、Cookie 与 Node 隔离。
- `test:runtime-tools -- --stream-ui` 使用真实 Electron、中心和实验 Runtime，模型为本地确定性实现。验证流式正文／工具在完成前可见、准确对象回执、协作调度、独立项目 Session，以及图片-only 消息通过资源暂存进入模型且不新建内容对象、不拼提示词。
- Computer Use 在独立测试窗口检查了浏览器单行布局、网址访问、返回／重入、网页与输入区共存，以及上下文跟随网页；只使用合成资料。
- 完整回归后进一步压缩朗读控件，将播放操作与标题并为一行，去掉重复关闭按钮；相关 8 项听写、长转写、百万字朗读、选区与截图用例再次全部通过，类型检查和构建也重新通过。
- 后续浏览器默认改为工作空间模式，侧栏显隐沿用用户偏好；侧栏开关固定在宿主原位置，不混进地址框。返回采用左箭头与工作台／项目文字，网页前进后退单独成组，地址栏使用中性底色。真实窗口截图已核对，坐标回归检查开关位于侧栏内，隐藏后也不与返回重叠。
- 半展开历史使用中性半透明底、细边界和轻阴影，文字不降透明度；完整记录不增加面板。修正生产 CSS 压缩后前缀属性取代标准属性的问题，最终 7 项界面回归全部通过，包括明暗模式、输入高度不变、失焦收起与固定、侧栏位置及窄窗口单行布局。

## 未包含的承诺

没有验证真实供应商的语音识别质量、真实账号登录与外部发布。自动音频测试使用合成音频和模拟供应商响应。浏览器仍是一个原生页面槽，不宣称已经支持完整多浏览器窗口／多标签生命周期。附件上传大小和类型限制是本版实现边界，不是书籍朗读长度限制。

本轮不包括专业富文本编辑器、小说／剪辑／编码专属应用、应用市场、移动端或云端团队验收。用户确认原窗口也是测试实例后，完整备份并更新原测试中心、Runtime 和桌面 profile，关闭额外验收窗口；原对象、输入、会话与投递逐项核对保留。仍未合并或对外发布。
