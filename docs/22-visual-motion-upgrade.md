## 设计依据

已核对 Apple HIG [Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 与 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。取其原则，不模仿系统组件的装饰，不把 Web 材质称为原生 Liquid Glass。

- 动效解释空间、层级与状态；短促、方向一致、可打断。输入、导航和焦点不等待动画完成。
- 高频文字编辑、消息增量和列表数据刷新不做整页入场或假打字。持续动画只用于真实进行中的状态。
- 工作画布清晰稳定；导航使用轻微中性色阶；临时浮层使用适量透底与模糊。文字、图标本身不透明。
- 控件、菜单、弹窗、检查器使用同一套边界、圆角、阴影与动效 token；强调色保留给焦点和必要操作。
- 减少动态效果时取消位移与循环动效；减少透明效果时改为实底，增加对比度时加强边界。

## 半开交流的布局决策

旧版历史是正常流中的灰卡片，其下面没有工作内容，透明度无法传达层级。本轮将未固定的半开历史作为输入框上方的临时浮层，保留画布在其背后；输入仍占位，完整记录仍是平面画布。固定交流、原生浏览器和短窗口使用占位布局，确保持续工作的控件不被遮挡。原生 WebContentsView 无法被宿主 CSS 真正模糊，明确使用同族实底材质，不抓取或复制网页来伪造玻璃。

半开与完整只改视图，不改 Session、草稿、应用挂载、权限、消息顺序和运行状态。系统截图选择阶段立即让出画布，不让过渡残影进入截图。

## 已实施的统一规则

- `visual-system.css` 作为最后加载的视觉层，统一明暗中性底色、文字层次、细边界、浮层材质和阴影。沿用四套强调色，主画布不使用满屏主题色。
- 高频按钮和焦点反馈 110 ms；菜单内容和弹窗入场 180 ms；临时历史、执行/理解侧栏和媒体面板入场 220 ms。这是本项目参数，不是 Apple 规定的时间值。关闭菜单立即取消交互，不让淡出遮住下一次点击。
- 输入框保持至少 60 CSS px 的文字区，没有独立工具顶行，没有入场位移；只改变焦点边框。菜单的顶层命中区域固定，只对内容做淡入。实测发现输入框位移会干扰嵌入应用的合成命中更新，已移除并补回归，未靠禁用背景应用指针来绕开。
- PDF 阅读工具通过 portal 并入现有工具栏；移除重复大标题、作者区和单独分页行。PDF 画布从顶栏下 8 px 开始，原 PDF 文件中的标题保持原样。版本、文件来源和只读信息未删除，收到文件信息中；选中文字仍可提问、批注和朗读。普通/窄窗口均验证，引用仍对应准确版本与页码。
- 批注标题和对象名合为一行；文本附件预览上限 680 px，图片/PDF 仍按媒体比例与视口显示；截图面板收紧无内容间距。表单值与属性名称区分层次。
- 不给每条流式增量、数据刷新、页面导航或输入焦点添加大幅运动。持续动效仅跟随真实流状态；不添加假打字、无意义弹跳或新状态栏。
