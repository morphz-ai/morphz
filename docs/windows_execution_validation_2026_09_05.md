# Windows 命令执行验证（2026-09-05）

本记录覆盖 Windows 命令执行修复与测试包，不代表完整发布门禁或所有平台验证完成。

## 验证环境

- Windows x86_64 实机；已有远程桌面登录会话。
- Dashboard 端到端测试服务以普通用户权限运行，使用单独端口与测试数据库。
- Windows 本机构建 `release` 优化版本；源码基线为 `dab4039f`，叠加本次执行与沙箱修复。其他开发任务的未提交修改未进入该测试包。
- 原运行实例和原数据库保留。初始化沙箱使用已授权的管理连接；后续 Dashboard 执行不要求管理员启动整个 Runtime。

## 修复范围

1. 执行输出按字节读取，优先解码 UTF-8，并在 Windows 对本地 OEM 编码回退。非 UTF-8 字节不会导致输出管道提前关闭。
2. Full Access 的执行结果明确报告 `sandbox_status: disabled`。
3. 私有 Window Station 创建被拒时使用当前 Window Station 内的私有 Desktop；其他错误仍然失败。该兼容路径保留独立 Desktop，站级剪贴板与 atom table 隔离弱于私有 Window Station。
4. Windows 精确路径 ACL 只处理已经存在的对象，避免将缺失的 `.env` 或配置文件建成目录。
5. 取消执行时检查进程句柄的退出状态，处理已经退出及检查与终止之间的退出竞态；活进程的权限错误仍然返回失败。
