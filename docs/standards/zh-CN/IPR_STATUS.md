## 1. 目的

本说明记录 Morphz 标准工作区的著作权、专利、贡献、商标与兼容性边界。除非某个文件附有
更具体的声明，它适用于结构化上下文、Agent Trajectory、Harness、HNS、Yao 与 Mind Frame
Exchange 文档。

Draft、Candidate 和 Final 表示技术成熟度，不改变某个已发布版本所适用的著作权许可证。

## 2. 著作权许可证

本工作区原创的规范文本、示例、Schema 和公开一致性测试夹具，依照
[Apache License 2.0](../../../LICENSE) 授权，并受仓库
[许可证适用范围](../../../LICENSE_SCOPE.zh-CN.md)约束。某个文件或独立发布制品如带有更具体的
许可证声明，仍适用该声明。

## 3. 专利立场

对 Apache-2.0 材料的贡献，适用 Apache-2.0 第 3 条的专利授权。授权仅覆盖贡献者有权许可，
并且会被该贡献单独或与接收该贡献的作品组合时必然侵犯的专利权利要求。参见项目
[专利政策](../../../PATENTS.zh-CN.md)。

当前政策不会在 Apache-2.0 已实际授予的权利之外，对独立实现增加单独的标准必要专利承诺。
在某项规范进入邀请独立生产实现或正式兼容性声明的阶段之前，新变元将判断是否需要单独的
必要权利要求承诺；任何此类承诺都必须经过明确采纳和法律审查。

## 4. 贡献

除非醒目标注 `Not a Contribution`，或另有书面协议，主动提交并拟纳入 Apache-2.0 材料的
贡献适用 Apache-2.0 第 5 条。贡献者同时在第 3 条规定的范围内授予专利许可，并且必须满足
[CONTRIBUTING.md](../../../CONTRIBUTING.md)中的来源规则。

## 5. 商标与兼容性声明

著作权和专利许可不授予 Morphz、Yao、Newvar、相关 Logo、官方兼容性标识或认证声明的使用权。
准确的指称性使用以及一致性规范允许的准确带版本声明，仍须遵守
[商标政策](../../../TRADEMARKS.zh-CN.md)。

通过公开一致性套件属于技术证据，本身不会授权使用官方 Logo、作出一般认证声明，或将某个
发行版表述为 Morphz 官方发行版。

## 6. 采用更强标准承诺前的审查

在某项规范从 Draft 进入邀请独立生产实现的更高成熟度之前，项目应当记录：

1. 所覆盖的准确规范、套件和 Profile 版本；
2. 是否采纳额外的标准必要专利承诺；
3. 成功实现可以使用的兼容性表述和标识；
4. 该版本适用的贡献与披露规则；
5. 对已知相关专利申请和第三方材料的法律审查结果。
