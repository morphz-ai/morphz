# Morphz v0.1.3

Runtime release focused on reliable task completion and task-scoped model
selection. This tag publishes Morphz Runtime and morphz-edge, not a separately
versioned Desktop application or a hosted Cloud service.

## Task reliability

- Bind delegated completion to the original task thread and its exact persisted
  result event. A progress inquiry or another reply in the same Session can no
  longer complete the original delegation. Recovery uses the same ownership
  checks and does not guess when attribution is ambiguous.
- Persist interrupted public model replies so their visible output survives a
  Runtime restart.
- Resolve waits on terminal Objectives correctly and preserve cancellation and
  interruption boundaries through context maintenance and nested evaluations.
- Keep follow-up delivery independent of blocking steering, and strengthen
  durable approval and provider-authentication recovery.

## Task-scoped model selection

- Add optional `model` and `reasoning_effort` parameters to Objective creation,
  thread creation/scheduling, subsequent scheduling, and delegation, with
  corresponding HTTP, SDK, CLI, and application support.
- Preserve explicit selections through tool continuations, waits, and recovery
  without rewriting the Session default. Omitting the parameters retains the
  applicable existing/default selection. Model allowlists and provider
  capabilities still apply.

See [task model selection](https://github.com/morphz-ai/morphz/blob/v0.1.3/docs/task_model_selection.md)
for the precedence and validation rules.

## Yao and maintenance

- Correct typed inference result contracts and use ordinary JSON for new typed
  data-result transport. Runtime-internal typed values remain separate from
  model-facing JSON. Add authoring checks, formatting, and raw strings.
- Preserve readable, correctly admitted v0.1.2 typed reference artifacts and
  their content hashes, including record-field references and suspended
  continuations. This is a storage reader, not a second source language: new
  programs use typed field access, and erroneous `produces` syntax stays
  rejected.
- Update `rustls` to 0.23.45 and `rustls-webpki` to 0.103.15, refresh license
  records, and resolve website build-tool dependency advisories.
- Keep remote storage and experimental Session I/O behind their existing
  opt-in feature boundaries; they are not enabled in the default release
  binaries.

## Upgrading

Stop the running Runtime and back up its configured data before replacing the
binary. Restart it and confirm `morphz --version` reports `0.1.3`.

This release prevents new delegation-result misattribution; it does not
automatically repair previously misattributed completions or silently rerun
their work. Inspect the original task thread and result history before deciding
whether any affected task needs recovery, especially when it may already have
produced external effects.

New HTTP requests reject unknown fields rather than silently ignoring them.
Callers and Harness authors should use the current documented request and Yao
contracts; storage recovery support is not permission to keep emitting an
incorrect request or source format.

## Distribution

Morphz and morphz-edge remain available for macOS Apple Silicon and Intel,
Linux ARM64 and x86_64, and Windows x86_64. Archives include license records and
required platform components, with accompanying SHA-256 checksums.
