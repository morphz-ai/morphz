## 结果

Morphz 正确 74/89，Codex 正确 74/89，均为 83.15%。逐题对齐后，共同通过 67 题、共同失败 8 题、仅 Morphz 通过 7 题、仅 Codex 通过 7 题。Morphz−Codex 为 0 个百分点；固定种子任务自助法 95% 区间为 [−7.87,+7.87] 个百分点，双侧精确 McNemar `p=1.0`。

Morphz 的 74 分采用官方验证器任务判定：正式批次中两个验证器超时任务保持最终文件、任务摘要和官方测试不变，以零模型顺序复评恢复为通过。Codex 的 74 分为冻结批次中的官方验证器结果；其三个 AgentTimeout 均已对称复核，最终得分不变。原始运行产物不被回写。
