# ME-08 受缓存缺陷影响的 API 等效成本记录

日期：2026-08-29

> 状态：仅作工程诊断，不进入论文结论。该运行启用了显式缓存模式，但追加式 Inbox 没有在传输层保留不可变增量块和历史断点，导致缓存率系统性偏低。

## 同口径原始记录

论文对 Morphz 与 Codex 均采用 Harbor 汇总的模型服务方 usage 字段。GPT-5.6 Sol 在复算日的公开 API 列表价为：未缓存输入 4 美元/百万词元、缓存输入 0.40 美元/百万词元、输出 20 美元/百万词元。

| 指标 | Morphz | Codex CLI 0.149.1 |
| --- | ---: | ---: |
| 输入词元 | 55,933,502 | 82,153,524 |
| 其中缓存输入 | 13,879,296 | 76,503,680 |
| 未缓存输入 | 42,054,206 | 5,649,844 |
| 输出词元 | 1,171,816 | 1,208,463 |
| 输入加输出 | 57,105,318 | 83,361,987 |
| 输入缓存率 | 24.81% | 93.12% |
| API 等效成本 | **197.20 美元** | **77.37 美元** |

成本公式为：

$$
C = 4U/10^6 + 0.4R/10^6 + 20O/10^6,
$$

其中 $U$、$R$、$O$ 分别是未缓存输入、缓存读取和输出词元。按原始 usage 计算，Morphz 总逻辑词元少 31.50%，API 等效成本为 Codex 的 2.55 倍。该成本比值记录了已确认缓存缺陷下的实际运行，不表示 Structured Context 或修复后 Morphz 的成本水平。

## Morphz Runtime usage 对账

对云端保留的 89 个 SQLite 数据库进行只读汇总，共得到 1,187 条 `runtime/model_usage` 事件：输入 56,250,302、缓存输入 13,902,848、缓存写入 0、输出 1,173,805，总计 57,424,107。按同一价表折算为 198.43 美元。

Runtime 汇总比 Harbor 汇总多 316,800 个输入词元和 1,989 个输出词元，对应 1.22 美元。Harbor 汇总使 Morphz 与 Codex 使用相同统计边界；Runtime 汇总用于内部账目对账。两种口径均不改变“该成本结果受缓存缺陷影响”的判定。

## 与上一轮 Morphz 的变化

上一轮 Morphz 的输入缓存率为 16.32%，同价表 API 等效成本为 221.30 美元。本轮输入缓存率提高到 24.81%，等效成本下降 10.89%。本轮同时包含 Runtime 修复与缓存布局变更，因此该变化只作为版本间工程结果，不单独归因于某一项修改。
