## 1. 决策摘要

Morphz 曾讨论过比较英文 Context 原语、中文原语、文言文或其他自然语言表达的实验。单纯的多语言对比主要测量模型的语言能力、预训练分布、Tokenizer 和提示长度，不能直接证明结构化 Context 或认知符号求值机制有效。

因此，本方向暂不加入当前 ME-00～ME-07 主计划，不改变既有实验优先级。只有在核心论文实验按计划完成、时间与模型预算充足时，才考虑将其作为扩展实验或附录。

若未来执行，研究问题应从“哪种语言效果更好”收敛为：

> 开放认知符号的求值是否主要依赖英文名称的既有词汇语义，还是能够由递归结构、显式操作说明和当前 Context 共同确定？

建议名称为 **Symbol Naming and Cross-Lingual Invariance**，而不是“多语言 Context Benchmark”。

## 2. 与主论文的关系

本 Proposal 可能补充以下次要判断：

1. 认知符号不必绑定于英文名称；
2. 在显式定义存在时，模型能否对不透明符号进行受 Context 约束的求值；
3. 已提交的结构化认知对象能否被另一种交互语言稳定引用并驱动行动；
4. Morphz 的程序—数据项语言是否在一定范围内具有表层命名鲁棒性。

它不能替代或直接支持以下核心主张：

- 结构化 Context 优于消息历史；
- 结果直接回流优于文本重解释；
- S-Expression 优于 JSON、AST 或自然语言程序；
- Runtime 权威边界、恢复或副作用安全有效；
- Morphz 在不同自然语言中普遍等价。

因此，本实验不属于 ME-01、ME-03 或 ME-04 的退出条件，也不是预印本发布门槛。

## 3. 为什么不应立即执行

### 3.1 与核心机制距离较远

当前论文最缺少的是结构化状态、结果回流、隐藏行动和权威提交的确认性因果证据。多语言差异属于表层表示与模型鲁棒性问题，优先做它会分散实验设计和模型预算。

### 3.2 混杂因素过多

直接比较英文、中文和文言文会同时改变：

- 模型训练语料覆盖；
- Token 数量与分词方式；
- 操作说明长度；
- 表达歧义；
- 语言正式程度；
- 模型对任务领域词汇的熟悉度。

如果没有等信息设计和因子拆分，结果很难解释。

### 3.3 现有实验已经出现语言混杂

历史 S-Expression VM 消融中，中文候选 Kernel 与英文外部 VM 同时改变了语言和协议表示。该结果只能作为可行性证据，不能据此归因于结构或语言。未来若执行本 Proposal，必须在主表示协议冻结后单独改变语言因素。

## 4. 候选研究问题

### RQ-L1：符号命名不变性

在结构、操作说明、任务信息和模型相同的条件下，将开放符号名称从具有语义的英文名称改为中文名称或不透明标识，是否显著改变求值正确率？

### RQ-L2：定义与词汇先验

当符号名称不透明时，显式操作说明和 Context 示例能否使模型恢复可靠求值？

### RQ-L3：跨语言认知连续性

一个 Session 使用语言 A 形成的稳定认知对象，能否被使用语言 B 的后续 Session 正确引用，并进入隐藏下游行动？

RQ-L3 测量的是跨语言连续性，不自动证明结构化状态优于文本历史。若要形成比较结论，仍需加入信息等价的文本或无类型状态对照。

## 5. 候选实验因子

### 5.1 最小主因子

保持同一递归结构、fixture、模型、预算和评分器，仅改变符号命名与操作说明：

| Arm | 符号名称 | 操作说明语言 | 目的 |
| --- | --- | --- | --- |
| `semantic_en` | 有语义英文名称 | 英文 | 常见预训练先验基线 |
| `semantic_zh` | 信息等价中文名称 | 中文 | 语义命名的跨语言对照 |
| `opaque_defined` | `sym-a7` 等不透明名称 | 与主实验相同的单一语言 | 隔离名称词汇先验 |

真正与论文机制最相关的是 `opaque_defined`，因为它检查模型是否能根据结构、显式定义和 Context 求值，而不是仅靠符号名称联想。

### 5.2 可选跨语言因子

在主因子完成且结果可解释后，可增加：

| Arm | 状态形成语言 | 后续任务语言 | 目的 |
| --- | --- | --- | --- |
| `en_to_en` | 英文 | 英文 | 同语言基线 |
| `zh_to_zh` | 中文 | 中文 | 同语言中文对照 |
| `zh_to_en` | 中文 | 英文 | 跨语言读取与行动 |
| `en_to_zh` | 英文 | 中文 | 反向跨语言读取与行动 |

结构化对象的稳定 ID、版本、来源和关系保持不变；隐藏行动评分器不依赖自然语言措辞。

### 5.3 文言文的处理

文言文不建议作为正式主 Arm。它会引入风格熟悉度、歧义和语料分布差异，科学解释力弱。若时间充足，可以作为探索性案例或附录中的定性展示，但不能用于主要统计结论。

## 6. 候选任务与指标

任务应复用已冻结的核心 fixture，不重新发明与主论文无关的语言任务：

- 引用解析与作用域；
- Observation 进入 Binding 和条件分支；
- 权威事实修订与陈旧状态拒绝；
- 跨 Session 使用稳定认知对象；
- 最终工具参数只能由当前权威状态推出。

候选主要指标：

- 隐藏行动成功率；
- 结果契约有效率；
- 稳定引用解析正确率；
- 修订与陈旧事实拒绝率；
- 跨语言状态复用正确率。

候选次要指标：

- 首次可解析率；
- 修复次数；
- 请求数；
- 输入/输出 Token；
- 延迟和成本。

Token 只作为成本与表示差异，不作为机制有效性的主要指标。

## 7. 实验设计纪律

如果未来进入 Pilot，至少遵守：

1. 在同一个模型内做配对比较；
2. Fixture、信息内容、结构、示例数量和输出契约保持一致；
3. 不把翻译长度差异伪装成结构差异；
4. 使用人工校核的双语操作说明，并记录翻译版本；
5. 主要评分由语言无关的确定性隐藏行动完成；
6. 报告每种语言下的 Token 差异，但不据此删除样本；
7. 至少包含一个强多语言模型和一个语言能力分布不同的模型，避免从单模型推断普遍性；
8. 不以“文言文也能运行”的个案宣称语言无关性。

## 8. 启动条件

本 Proposal 只有同时满足以下条件时才进入协议设计：

1. ME-00 已完成并通过可重放 Smoke Run；
2. ME-01 核心三 Arm 已完成 Pilot，任务与评分器具备区分力；
3. ME-02/ME-03 的核心协议已经冻结或完成，不会被本实验干扰；
4. 路演关键交付已经结束；
5. 预印本最低证据包进度良好，没有更高优先级缺口；
6. 有明确的额外时间和模型预算；
7. 中英文翻译与等信息控制可以人工复核。

任一条件不满足时，本方向继续保持 Deferred。

## 9. 停止条件

即使进入 Pilot，出现以下任一情况也应停止扩展：

- 核心实验进度延误；
- 语言 Arm 无法做到信息等价；
- 主要差异明显来自模型不具备目标语言能力；
- 隐藏评分器无法与表面语言解耦；
- Pilot 只得到 Token/表达长度差异，没有机制层解释；
- 额外模型调用会挤占 ME-01～ME-05 的确认性预算。
