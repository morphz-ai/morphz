# 持续会话与并发执行

状态：已实施，完成本轮开发验收；不是正式发布。此决策取代 15、16 中按页面划分默认 Session 和按输入排列完整消息流的规则。

## 产品规则

- 命名会话从侧栏项目行右侧的方框笔形按钮直接新建，现有会话嵌套在项目下；重命名、归档和恢复归条目菜单。顶栏不再设会话选择器，且不添加全局新建对话。切换会话保留同项目已打开的应用与对象，创建成功聚焦输入，迟到回执不覆盖后续导航。
- 个人中心默认使用一条持续会话，贯穿对话、事项、工作台与未明确选择内部会话的项目。项目内部命名会话仍可独立使用；团队授权与 Context 隔离不合并。
- 导航入口、对象归属、交流记录与实际执行范围分别管理。查看执行不改变输入目标；从事项打开对象不跳回创建来源。
- 输入关联跟随当前视图或具体对象。打开事项就关联该事项，返回列表就关联事项视图；这是下一次 activation 的范围，不是 Session 切换，也不会重定向已经提交的工作。
- 每条输入捕获工作项目、对象版本、应用 Harness 与作者。共享 Session 的工具权限从 Runtime 的真实执行根及持久输入绑定解析，不从当前页面或模型参数推断。
- 旧输入、Session 和在途投递不改写、不重放。默认历史兼容汇总，独立会话保留；原有草稿仍可恢复。
- 主消息流按发布顺序排列；来源引用保留因果关系，但不把晚到交付插回原问题下面。流式消息首次出现后位置稳定，后续交付独立追加。
- 可收起、固定、调宽的右侧执行面板展示概览及单项过程，包括并发分支、工具、审批和结果。原消息上用轻量运行标记进入详情；悬停仅提供摘要。
- 详细工具过程不占满主交流；失败、未发送、审批仍可发现。运行状态以中心回执为准，断线不伪装为运行；减少动态效果时使用静态标记。

## 验收

- 跨两个项目发送并行输入，共用默认 Session，但对象写入、工具权限及取消分别指向正确工作。
- 切页、查看执行、刷新、保存工作台为项目不重放任务、不丢历史或草稿；项目命名会话及团队隔离不回退。
- 慢任务、后发快问答、慢任务交付按真实时间呈现，流式增长不重排，向上阅读不抢滚动。
- 原消息进入对应执行；右栏能独立停止、查看调用和审批，不能误停其他工作。
- 桌面明暗主题、窄窗口、键盘、固定及调宽经过实际 Electron 检查。

## 本轮验证记录

- 构建、类型检查、94 项 Node 测试通过。双项目共享 Session、独立命名会话、真实输入根授权、跨根拒绝、线程版本冲突、停止范围与重启不重放由确定性协议测试覆盖。
- 并发界面用例验证慢工作与后发快问答的交付顺序、原输入运行标记、准确详情、分支继续运行、停止待确认、固定、调宽和切页后的共享历史；流式专项验证首段位置、真实增量与最终去重。
- 最后一轮全量 52 项界面用例中 51 项通过，1 项关闭弹窗后的输入焦点检查偶发失败。随后将真实 Electron 与浏览器回归串行运行，相关应用与输入焦点 8 项组合复测全部通过。先前应用启动台的原生点击等待补齐首轮绘制后，相关全量用例通过。保留这些失败记录，不据此宣称所有偶发焦点问题都已根治；重复运行同一中心的有状态夹具也不能当作独立测试轮次。
- 隔离的真实 Runtime 与 Electron 经本机确定性模型完成共享默认 Session 的工具调用、对象创建、文字及工具参数流式展示、最终回复去重、重开恢复，以及独立项目会话验证。执行侧栏的固定、键盘调宽、明暗模式和 760×540 窗口已截图检查。没有用用户中心发送测试消息或调用付费模型。
- 独立开发中心与 Runtime 在线备份后更新。原有 5 个项目、5 条会话记录、4 个对象、14 条输入、96 条操作记录、4 个传输 Session 与 14 条投递逐项一致；已有未来定时安排的身份、版本、执行时间和状态保留，没有重放。日常中心没有修改。
- 用户机器处于锁定状态，无法通过前台自动化核对原窗口；服务健康、调度读取和原数据已验证，界面验收来自隔离的真实 Electron。代码尚未提交或发布。
